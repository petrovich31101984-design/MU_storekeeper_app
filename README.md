# Система медицинского учёта (к) — приложение кладовщика

Третье приложение системы АлкоСпас рядом с приложением руководителя (`pcmanapp`) и сотрудника (`mobileapp`).
Работает с той же Google-таблицей и тем же Apps Script — обновлять скрипт не нужно.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3002
npm run build      # сборка в dist/
npm run typecheck
```

Порты: 3000 — сотрудник, 3001 — руководитель, 3002 — кладовщик.

## Подключение и вход

1. На первом экране вставьте адрес веб-приложения Apps Script (тот же, что у руководителя).
2. Вход — персональный номер и пароль из листа «Сотрудники»; должность должна содержать «Кладовщик».

## Разделы

Панель кладовщика, Номенклатура, Приход к сотруднику, Расход у сотрудника, Остаток у сотрудника,
Возвраты, Сообщения, Отчёты, Архив, Настройки.

Разделы перенесены из приложения руководителя (`pcmanapp/src/App.tsx`) и работают так же. Отличия:

- действия подписываются кладовщиком: «Кем внесено», «Кем скорр.», «Кем создано» — `Кладовщик: ФИО`;
  записи в «Журнал изменений» — с ролью «Кладовщик» и устройством «Приложение кладовщика»;
- в «Сообщениях» кладовщик — адресат `STORE` (вкладка «Кладовщик» в приложении сотрудника);
  переписка сотрудников с руководителем (`MGR`) здесь не видна;
- нет разделов «Сотрудники» и «Журнал».

## Устройство кода

- `src/App.tsx` — разделы (из приложения руководителя) + вход кладовщика;
- `src/services/googleSheets.ts` — чтение/запись листов (из приложения руководителя), запросы идут через `src/api`;
- `src/api/index.ts` — подключение к Google-таблице и вход кладовщика.
